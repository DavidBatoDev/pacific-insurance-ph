# Relationship Events Module

## Pacific Insurance PH Operations Platform

Version 1

The system shall support configurable relationship event types.

Each event type shall contain:

- Event Name
- Description
- Active Status
- Reminder Timing
- Default Action Type

Default action types:

- Create Task
- Send Email
- Send SMS
- Send Gift Reminder
- Manual Follow Up

Administrators may create, edit, activate, or deactivate event types without developer assistance.

Examples:

- Birthday
- Welcome Client
- Policy Anniversary
- Renewal Thank You
- Referral Thank You
- Claim Approval Follow Up
- Retirement

Future automation capabilities may be added in later phases.
