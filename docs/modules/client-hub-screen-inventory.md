# Client Hub Screen Inventory

## Pacific Insurance PH Agency Operations Platform

# Purpose

Define all client-facing screens within the Client Hub module.

The Client Hub is a secure, read-only experience that allows clients to monitor their relationship with Pacific Insurance PH without requiring a full client portal.

# Navigation Structure

Client Hub

├── Home Dashboard

├── My Policies

├── My Applications

├── My Claims

├── My Renewals

├── My Travel Insurance

├── My Documents

├── Recent Activity

└── Contact Pacific Insurance PH

# Screen 1: Home Dashboard

Purpose:

Provide a summary of all important client information.

## Components

### Welcome Section

Display:

- Client Name
- Last Login / Last Access
- Assigned Contact

### Active Policies Summary

Display:

- Total Active Policies
- Policy Status Overview

Example:

- Blue Royale
- TravelSafe

### Applications Summary

Display:

- Applications In Progress
- Current Status

### Claims Summary

Display:

- Open Claims
- Claim Status

### Renewals Summary

Display:

- Upcoming Renewals
- Due Dates

### Travel Insurance Summary

Display:

- Open Travel Requests
- Recent Travel Policies

### Action Required Section

Purpose:

Highlight anything needing client attention.

Examples:

- Missing Documents
- Awaiting Payment
- Additional Claim Requirements

### Recent Activity

Display latest updates.

# Mobile Design Requirements

The Client Hub should be optimized for:

- Mobile phones
- Tablets
- Desktop

Primary usage is expected from mobile devices accessed through:

- Viber
- WhatsApp
- Email Links
- SMS Links

# Security Requirements

All screens must:

- Use secure access tokens
- Respect document visibility permissions
- Hide internal-only information
- Log access events

# Version 1 Scope

Included:

- Read-only access
- Status visibility
- Document downloads
- Contact information

Not Included:

- Document uploads
- Profile editing
- Claim submission
- Application submission
- Online payments
- Messaging system

# Success Criteria

Clients can:

- Understand their current status
- Access their documents
- Know their next required action
- Contact Pacific Insurance PH when needed

without requiring direct staff assistance for routine updates.
