# MVP Scope & Phase Roadmap

## Pacific Insurance PH Agency Operations Platform

# Purpose

Define what will be included in Version 1 (MVP), what will be deferred to Phase 2, and what remains part of the long-term vision.

This document protects the project from:

- Scope creep
- Budget overruns
- Delayed launch
- Over-engineering

The goal is to launch a useful operational platform as quickly as possible while creating a foundation for future growth.

# Project Philosophy

Version 1 should focus on:

### Operational Efficiency

Helping Matt and Eman:

- Manage clients
- Manage applications
- Manage renewals
- Manage claims
- Manage travel insurance
- Manage documents
- Reduce manual follow-ups

# Version 1 Exclusions

The following are intentionally excluded.

## Online Payments

Not Included

Examples:

- GCash Integration
- Maya Integration
- PayMongo
- Payment Gateways

Reason:

Adds complexity and compliance requirements.

## Pacific Cross Integrations

Not Included

Examples:

- Policy API Integration
- Claims API Integration
- Renewal API Integration

Reason:

Pacific Cross systems are outside project control.

## Portal Automation

Not Included

Travel purchases remain manual.

## Client Upload Portal

Not Included

Clients cannot upload documents directly.

## Client Messaging

Not Included

No internal messaging system.

## Mobile App

Not Included

Web application only.

Mobile responsive design required.

## AI Features

Not Included

Examples:

- AI Recommendations
- AI Underwriting
- AI Claims Analysis

## Commission Tracking

Not Included

May become a future module.

## Referral Management

Not Included

Future module.

# Success Criteria

Version 1 is successful when:

- Matt and Eman stop relying on spreadsheets
- Client information is centralized
- Applications are trackable
- Renewals are not missed
- Claims are organized
- Travel insurance is manageable
- Documents are searchable
- Clients can self-check status through the Client Hub
- Administrative workload is significantly reduced

# MVP Definition

The MVP is not a complete insurance platform.

The MVP is a centralized operational system that allows Pacific Insurance PH to manage its business efficiently while creating a foundation for future growth and automation.
